Question Paper Printing

East Delta University — prints question papers already sorted room by room

← Seat Plan Generator

1 · Exam details & Summary Table

Copies per course and room. Imported automatically when opened from the Seat Plan Generator. Otherwise load the last generated plan, paste the Summary Table (copied from the Word file or Excel), or enter it manually. All numbers can be edited.

2 · Question papers (one PDF per course)

Choose the PDF for each course. Courses without a PDF are skipped with a warning.

3 · Build the print file

Each room batch starts with a separator page (room, course, expected students, Present/Absent). After building, open the PDF, press Ctrl+P, keep Copies = 1 and print as the green message says.
